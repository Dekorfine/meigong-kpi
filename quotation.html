📘 报价单工具使用说明

🎯 这个工具能做什么

一份表单一次填好，自动生成 4 份单据：

  • 报价单 (Quotation) — 给买家看的报价
  • 采购单 (PO) — 买家发给卖家的订单
  • 形式发票 (PI) — 卖家给买家的正式发票
  • 装箱单 (Packing List) — 出货时附的装箱明细

📝 基本操作步骤

  1. 选择卖家网站（顶部下拉框）—— 系统会自动填好卖家信息、订单号前缀、银行信息（如 Radilum 系列）。
  2. 填写订单信息：报价单号、PI 号、PO 号会自动联动；只要改其中一个的末尾数字，其它自动同步。
  3. 选择货币：默认 USD，可切到 CNY / EUR / GBP / AUD / CAD。切换货币后，运费输入框的币种提示也会自动变。
  4. 填买家信息和收货信息。
  5. 填运费：直接按你刚才选的货币填整数即可（比如选了 CNY 就填 ¥68 而不是 9.5 美元换算）。
  6. 添加产品项目：每行可以填 SKU、描述、数量、单价、箱号、净重、毛重、体积。
  7. 插入图片：在某行的"图片"格里直接 Ctrl+V 粘贴 截图，或拖文件进去。图片会出现在报价单和 PI 上。
  8. 设置折扣百分比（如果有）。
  9. 选条款模板 或自己手动编辑条款文本（手动改过之后系统就不再覆盖你的内容）。
  10. 切换右侧预览 Tab 检查每份单据，确认无误后点击对应 Tab 的 📥 导出此 PDF 按钮。

📥 PDF 导出

  • 预览区有 4 个 Tab：Quotation / PO / PI / Packing List。
  • 每个 Tab 顶部都有 📥 导出此 PDF，只导出当前这一份。
  • 右上角的 📄 导出全部 把 4 份一起打印（旧版本的行为）。
  • 导出原理：调用浏览器打印对话框，选"另存为 PDF"即可。Chrome / Edge / Safari 都支持。

☁️ 云端保存（多次保存不再产生重复文件）

  • 第一次使用前点右上角 ⚙ 齿轮，填入用户名和 GitHub Token。
  • 点 ☁ Save to Cloud 或按 Ctrl+S 即可保存。
  • 同一个 PI 号会覆盖原文件——改 3 次只留最后一次，不再像旧版那样累积 3 份。
  • 列表里如果显示 [旧] 标记，那是旧版按时间戳累积的重复文件。当列表里有重复时，状态栏会出现 "清理 N 个旧版重复文件" 链接，点一下就自动只保留每个 PI 号最新的一份。
  • 每次进入页面会自动加载所有云端记录，按用户筛选、按名称搜索均可。

💾 本地保存 & 草稿恢复

  • 切到本地保存 Tab，可以在浏览器里临时存几份。
  • 所有操作都会被 自动保存为草稿，意外关掉浏览器再打开会自动恢复上次的内容。
  • 点击 "开始新报价" 才会清空当前表单。

🏦 PI 银行信息开关

表单上方有 "PI 选项 / PI Options" 区，里面的 "显示收款人银行信息" 复选框控制 PI 上的银行信息块：

  • 勾上 → PI 上显示银行信息（默认状态）。
  • 取消勾选 → PI 上不显示，导出 PDF 也不会有这块。
  • 这个状态会跟着报价单一起保存到云端。

🌐 多语言

顶部"语言"下拉可以切换：英文、中英对照、西班牙语、德语、法语、阿拉伯语、俄语。表单和单据上的固定文案都会跟着切换。

⚡ 快捷键

  • Ctrl+S — 保存到云端
  • Ctrl+V 在图片格里 — 粘贴图片

❗ 常见问题

  • 预览没更新？ 输入后约 200ms 才刷新（防抖），稍等一下。
  • 导出后图片不显示？ 确认浏览器打印选项里勾上"背景图形 / Background graphics"。
  • 云端保存失败？ Token 可能过期，找管理员要新的，在 ⚙ 设置里更新。
  • 想完全删除某份云端记录？ 在列表里点右侧的 ✕ 按钮。
